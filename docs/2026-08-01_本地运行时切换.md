# 本地运行时切换

本项目保留 Cloudflare 部署模式，同时提供本地 PostgreSQL 和本地文件对象存储模式。

## 模式

- `MAHOSHOJO_RUNTIME_MODE=cloudflare`：使用现有 Cloudflare D1、R2、OpenNext 运行链路，默认值。
- `MAHOSHOJO_RUNTIME_MODE=local`：使用 `DATABASE_URL` 指向的 PostgreSQL，以及 `MAHOSHOJO_LOCAL_OBJECTS_DIR` 指向的本地对象目录。

本地 PostgreSQL 模式沿用现有 D1 兼容边界，因此业务仓库和 Better Auth 不需要分叉。首次有服务端数据库请求时，会根据 `lib/database/schema.sql` 自动初始化本地数据库，并写入内部版本标记；不会读取 Cloudflare D1 配置。

## 使用

1. 安装项目依赖，并确保本机 PostgreSQL 已创建数据库和用户。
2. 在本地环境文件中设置 `MAHOSHOJO_RUNTIME_MODE=local` 和 `DATABASE_URL`。
3. 使用 `pnpm dev:local` 启动，或手动设置同一模式变量后执行 `pnpm dev`。
4. 切回 Cloudflare 时设置 `MAHOSHOJO_RUNTIME_MODE=cloudflare`，或删除该变量后重新启动服务。

本地对象文件会写入 `.local/objects`，该目录已加入 `.gitignore`，不会进入提交或推送。

## 注意

本地模式不启用 Cloudflare Rate Limiting 绑定，因此相关限制器在本地返回“未绑定”状态；业务鉴权、所有权校验、安全检查和审计逻辑仍然执行。图片、AI 供应商和邮件等外部服务仍按各自环境配置运行，不会被自动替换或记录密钥。
